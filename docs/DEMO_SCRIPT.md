# 5-minute demo script

1. Open the app and enter a sample profile with Python, SQL, Pandas and analytics interests.
2. Show the top career matches and explain that scores are relative ranking scores.
3. Open Skill Gap and select Data Analyst or Machine Learning Engineer.
4. Generate a roadmap and open the resource links.
5. Mark one task complete and show the progress dashboard update.
6. Ask the Career Assistant what to learn for the selected role; show the retrieved records and sources.
7. If configured, repeat with Gemini enabled and explain that retrieved local records ground the answer.
8. Close with limitations and planned evaluation rather than claiming guaranteed job outcomes.
